# 七弦有象 · 古琴艺术

古琴艺术网站：画卷、识琴、琴式、琴史、琴派、数字展览《弦上有象》、抚琴、文创。

## 发布到 GitHub Pages

1. 新建一个 Public 仓库，把本文件夹里的全部文件上传（`index.html` 必须在仓库根目录）。
2. 仓库 Settings → Pages → Branch 选 `main`，文件夹选 `/ (root)` → Save。
3. 一两分钟后，页面顶部会显示网址：`https://用户名.github.io/仓库名/`。

## 文件说明

- `index.html`：整个网站（图片、声音、代码都已打包在内），只有它是网站运行必需的。
- `src/`：网站源文件，供以后修改使用；运行 `python3 build.py`（在 src 目录内）会重新生成 index.html。
- `.nojekyll`：让 GitHub Pages 原样发布文件。

画中人物取自宋徽宗《听琴图》（故宫博物院藏）与刘松年《听琴图》（克利夫兰艺术博物馆藏），均为公有领域作品。
